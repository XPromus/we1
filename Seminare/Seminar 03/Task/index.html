Implementiert die Funktionen in seminar.js. Diese Seite prüft automatisch, grün = bestanden, rot = noch offen. Rote Tests zeigen nur, was euer Code geliefert hat, die erwarteten Werte verrät die Prüfung absichtlich nicht. Jeder Test läuft einzeln: Wirft eine Funktion noch einen Fehler, wird nur ihr Test rot, die anderen laufen weiter. Aufgabe 6.2 schreibt ihr nicht in Code, sondern sortiert Karten direkt auf dieser Seite. Die Vorhersagen aus Aufgabe 2 und die Hoisting-Vorhersage aus Aufgabe 3.2 tragt ihr ebenfalls direkt hier ein.
